# Release 0.4.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut release `v0.4.5` — bump workspace version, rewrite `CHANGELOG.md` in business-value voice per the approved filter rules, commit, tag, and push so cargo-dist publishes `@getspur/spur@0.4.5` to npm.

**Architecture:** Single-version source of truth (`Cargo.toml` workspace.package) inherited by all nine crates. Changelog is the public Release body — cargo-dist extracts the matching `## v0.4.5` H2. Tag push on `main` is the only CI/CD trigger needed.

**Tech Stack:** Rust workspace (Cargo), cargo-dist 0.31.0, GitHub Actions, npmjs.com (`@getspur` scope), `getspur/spur-releases` public repo for artifacts.

**Spec:** `docs/superpowers/specs/2026-04-19-release-0.4.5-changelog-design.md`

### Task 3: Rewrite CHANGELOG.md for v0.4.5

**Files:**
- Modify: `CHANGELOG.md` (full replacement of current `## Unreleased` section)

Context: the current `CHANGELOG.md` has a single `## Unreleased` H2 whose body covers **only** the Brain delegation framework. Per the spec's filter rules, Brain delegation is **preview/opt-in** in release builds — its current `### Added` framing is wrong for 0.4.5. The rewrite replaces the entire `## Unreleased` section with a full v0.4.5 entry and starts a new empty `## Unreleased` on top.

- [ ] **Step 1: Replace the file contents**

Overwrite `CHANGELOG.md` with exactly the following content:

```markdown
## Unreleased

## v0.4.5 — 2026-04-19

Spur 0.4.5 focuses on getting around faster and trusting what you see. A new universal palette (Ctrl+K) jumps you between sessions, workers, traces, and commands from anywhere. The `@mention` and `/slash` pickers now share one consistent interface. Agent output renders markdown and mermaid diagrams inline, and streaming stays smooth under bursty traffic.

### Added
- **Universal palette (Ctrl+K).** Fuzzy-search and jump to any session, worker, trace entry, or command from anywhere in the TUI. A `[Ctrl+K: go]` badge in the status bar reminds you it's there.
- **Unified completion for `@mention` and `/slash`.** Both now flow through the same picker — same keys, same preview, same ranking. One interface to learn.
- **Rerun recent prompts with Ctrl+R.** Session picker surfaces your recent prompts; pick one to rerun against the current session.
- **Auto-resume landing.** Launching spur drops you straight back on the last session you were working in.
- **Markdown and mermaid in agent output.** Rich content renders inline in the trace view — no more raw source for formatted replies or diagrams.
- **Dashboard view.** New top-level view for at-a-glance status across sessions and workers.
- **Skills installer across adapters.** `.spur/skills/` installs to Cursor, Codex, Kiro, Gemini, and OpenCode in one step, with edits you own preserved on upgrade.
- **Delegation visibility in the timeline.** Delegation plans now appear in the TUI timeline as they happen; `list_available_workers` returns richer descriptors (tier, cost, suitability hints).

### Improved
- **Smoother streaming.** A new scroll anchor and per-frame drain cap keep long, bursty outputs readable instead of jittery.
- **Faster palette and pickers.** Single-pass reranking and cached search patterns.
- **Session metadata persists across restarts.**

### Preview features (opt-in)
- **Brain delegation framework.** A new orchestration model for deciding which worker handles a task. Opt in via your config:
  ```toml
  [brain.delegation]
  framework = "v1"
  ```
  Release builds default to `legacy` for 0.4.5; the v1 framework will become default once it stabilizes.
```

(Everything above replaces the existing file contents. Do not preserve the old `### Added` / `### Changed` bullets — they are superseded by this structured entry.)

## Notes for the executor

- **Task 6 Step 3 is irreversible.** Once the tag pushes and cargo-dist publishes to npm, the 0.4.5 version on npm cannot be re-published with different bits. If any post-release verification fails (Task 7), the fix is a new `0.4.6` release, not re-tagging.
- **Do not run `cargo dist init`.** We are not regenerating `release.yml`; we are using the existing one unchanged.
- **Do not bump `resource/superpowers/package.json` or `.opencode/package.json`.** Those are unrelated bundles. The spur CLI npm package is generated by cargo-dist from `Cargo.toml`.
- **Untracked files** (`.cursor/`, `CLAUDE.md`, `.spur/skills/...`, `.superpowers/`, `__pycache__/`) should remain untracked throughout. Do not `git add -A` at any point.
