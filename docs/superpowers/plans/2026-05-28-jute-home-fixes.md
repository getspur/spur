# Jute HomePage Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three real gaps on the Jute notebook HomePage: rename is silently broken because Tauri webview ignores `window.prompt`; discard-scratch is silently broken for the same reason on `window.confirm`; and "New notebook" cannot target an explicit save location.

**Architecture:**
- **Frontend (TS/React):** Replace `window.prompt` with inline input editing on each NotebookCard; replace `window.confirm` with a small in-app `ConfirmModal`; add a "New here…" button that uses `@tauri-apps/plugin-dialog`'s `save()` to pick a target `.ipynb` path.
- **Backend (Rust/Tauri/daemon):** Add a new `DaemonControlCommand::NewAt { path }` variant and Tauri command `new_notebook_at_via_daemon(path)` that writes an empty `.ipynb` at the chosen path and opens it through the existing daemon path. Reuse `create_untitled_notebook_in_dir`'s contents-builder.
- **Bindings:** Regenerate ts-rs bindings so the new daemon variant appears in `DaemonControlCommand.ts`.

**Tech Stack:** React 19, wouter, Tailwind, Vitest, Tauri 2 (`@tauri-apps/api/core`, `@tauri-apps/plugin-dialog`), Rust 2021, `ts-rs`, anyhow, tokio.

**Pre-flight invariants worth keeping:**
- Daemon `Rename { from, to }` already accepts arbitrary `to` paths (`tokio::fs::rename` in `crates/spur-notebook/src/mcp/mod.rs:870-907`). Do **not** add backend rename validation; the UI is the only thing blocking moves and we want renames-within-folder for v1.
- All daemon ops go through the unix socket (`crates/spur-notebook/jute-notebook/src-tauri/src/commands.rs:497-543`). Do **not** introduce in-proc shortcuts.
- ts-rs binding files have a "Do not edit this file manually" header — regen via `cargo test -p jute --lib bindings_emit` (existing crate ts-rs test that writes bindings).

// crates/spur-notebook/jute-notebook/src/ui/home/renameValidation.ts
export type RenameValidation =
  | { ok: true; fileName: string }
  | { ok: false; error: string };

export function validateRename(input: string): RenameValidation {
  const trimmed = input.trim();
  if (!trimmed) {
    return { ok: false, error: "Notebook name must not be empty." };
  }
  if (/[\\/]/.test(trimmed)) {
    return { ok: false, error: "Notebook name must not contain path separators." };
  }
  const fileName = trimmed.toLowerCase().endsWith(".ipynb") ? trimmed : `${trimmed}.ipynb`;
  return { ok: true, fileName };
}
```

// ConfirmModal.tsx
import { useEffect } from "react";

export type ConfirmModalProps = {
  body: string;
  confirmLabel: string;
  danger?: boolean;
  onCancel: () => void;
  onConfirm: () => void;
  open: boolean;
  title: string;
};

export default function ConfirmModal({
  body,
  confirmLabel,
  danger = false,
  onCancel,
  onConfirm,
  open,
  title,
}: ConfirmModalProps) {
  useEffect(() => {
    if (!open) return;
    const handler = (event: KeyboardEvent) => {
      if (event.key === "Escape") onCancel();
    };
    window.addEventListener("keydown", handler);
    return () => window.removeEventListener("keydown", handler);
  }, [open, onCancel]);

  if (!open) return null;

  return (
    <div
      aria-modal="true"
      className="fixed inset-0 z-40 flex items-center justify-center bg-black/30"
      onClick={onCancel}
      role="dialog"
    >
      <div
        className="w-full max-w-md rounded border border-gray-300 bg-white p-5 shadow-xl"
        onClick={(event) => event.stopPropagation()}
      >
        <h2 className="text-lg text-gray-950">{title}</h2>
        <p className="mt-2 text-sm text-gray-600">{body}</p>
        <div className="mt-5 flex items-center justify-end gap-2">
          <button
            className="rounded border border-gray-300 px-3 py-2 text-sm text-gray-600 transition-colors hover:border-black hover:text-gray-950"
            onClick={onCancel}
            type="button"
          >
            Cancel
          </button>
          <button
            autoFocus
            className={[
              "rounded px-3 py-2 text-sm text-white transition-colors",
              danger ? "bg-red-600 hover:bg-red-700" : "bg-gray-950 hover:bg-black",
            ].join(" ")}
            onClick={onConfirm}
            type="button"
          >
            {confirmLabel}
          </button>
        </div>
      </div>
    </div>
  );
}
```

        code: "invalid_params".to_string(),
        message: "new_at requires path".to_string(),
    })?;
    let path = resolve_notebook_path(path);
    self.save_current().await?;
    create_empty_notebook_at(&path)
        .await
        .map_err(|error| BridgeError::Handler {
            code: "new_at_failed".to_string(),
            message: error.to_string(),
        })?;
    let path = self.open_path(path).await?;
    if let Err(error) = self.record_recent_open(&path).await {
        warn!(%error, path = %path.display(), "failed to record recent notebook");
    } else {
        self.windows.emit_recents_changed();
    }
    Ok(DaemonControlSuccess::path(path))
}
