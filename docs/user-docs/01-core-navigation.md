# Core Concepts & Navigation

Welcome to the Spur Text User Interface (TUI). This guide explains the fundamental layout, concepts, and how to navigate the application.

## The Dashboard

When you start Spur, you'll land on the **Dashboard**. This is your command center. It consists of three main areas:

1. **Agents Tree (Left Panel):** A hierarchical view of your active and past agent sessions. You can browse the lineage of your tasks here.
2. **Activity Log (Right Panel):** A timeline of events, messages, and actions happening across your agents.
3. **Input Bar (Bottom):** Your primary way to interact with the system, send messages, and execute commands.

### Dashboard Modes

The Dashboard operates in two distinct modes to keep navigation separate from typing:

> 🎥 **Video Placeholder:** [Demonstrate switching between Navigation Mode and Compose Mode using the Tab key, showing how the UI focus border shifts.]

* **[NAV] Navigation Mode:** When the input bar has a gray border, your keystrokes control the application. You can scroll, switch panels, or jump to specific views.
* **[INSERT] Compose Mode:** When the input bar has a cyan border, everything you type goes into the input field.

**Switching Modes:**
* Press `Enter`, `i`, `a`, `I`, `A`, or `o` to enter **Compose Mode**.
* Press `Esc` to return to **Navigation Mode**.

### Navigating the Dashboard

While in **[NAV]** mode, use these keys to move around:

* **`Tab` / `Shift+Tab`:** Cycle focus between the Agents Tree and the Activity Log.
* **`1`:** Jump directly to the Agents Tree panel.
* **`3`:** Jump directly to the Activity Log panel.
* **`j` / `k` (or `Up` / `Down`):** Move your selection up or down within the focused panel.
* **`PgUp` / `PgDn`:** Scroll up or down by a full page.
* **`Ctrl+d` / `Ctrl+u`:** Half-page scroll.
* **`g` / `G`:** Jump to the top (`g`) or bottom (`G`) of the list.
* **`c`:** Collapse or expand the selected subtree in the Agents Tree.
* **`Enter`:** Focus the selected agent in the Agents Tree to view its **Detail Pane**.

## The Detail Pane

When you select an agent in the Agents Tree and press `Enter`, the Activity Log is replaced by the **Detail Pane**. This pane provides deep insights into the focused agent's session and contains several tabs:

* **Stream:** The live output and execution trace of the agent.
* **Artifacts:** Files created or modified by the agent.
* **Attempts:** The history of attempts for the current task.
* **Task:** The prompt or task specification given to the agent.
* **Review:** If the agent requires approval, this tab shows the pending review details.

**Detail Pane Navigation:**
* **`h` / `l` (or `Left` / `Right`):** Cycle through the tabs.
* **`Ctrl+1` through `Ctrl+5`:** Jump directly to a specific tab (Stream, Artifacts, Attempts, Task, Review).
* **`j` / `k`:** Scroll the content within the current tab.
* **`o`:** Toggle observe collapsed mode (Stream tab only).
* **`Esc`:** Unfocus the agent and return to the Activity Log.

## Other Views

Spur has several other top-level views you can access from the Dashboard:

* **Session Picker (`s`):** Opens a menu to browse, resume, archive, or rename past sessions.
    * `Enter` to resume or create a new session.
    * `n` to start a new session.
    * `R` to rename.
    * `x` to archive/unarchive.
    * `p` to pin.
    * `/` to focus the search field.
    * `Esc` to return to the Dashboard.
* **Issue Browser (`2`):** If issue tracking is enabled, this view lets you browse and manage issues.
    * `Enter` to open/close issue detail.
    * Status updates: `o` (open), `w` (in progress), `b` (blocked), `x` (closed).
    * `W` to work on an issue.
* **Mermaid Viewer (`Alt-v`):** Opens an overlay to view rendered Mermaid diagrams generated by agents. Use `[` and `]` to cycle through diagrams and `Esc` or `q` to close.
* **Insights (`Alt-a`):** Opens the analytics dashboard.

## Global Shortcuts

These shortcuts work from almost anywhere in the application:

* **`Ctrl-K`:** Open the Command Palette to quickly run commands, jump to sessions, or switch workers.
* **`?`:** Toggle the Help Overlay.
* **`Ctrl-C`:** Quit the application (press twice to force quit).
* **`q`:** Quit the application (from Dashboard Navigation mode).
* **`u` / `Ctrl-Z`:** Undo destructive actions (like archiving a session).

## The Status Bar

At the very top of the screen, you'll see the **Status Bar**. It provides a quick summary of the system's state:

* **Hints (Left):** Shows available hotkeys for your current context (e.g., `[j/k]scroll`, `[Esc]back`).
* **Metrics (Right):**
    * **Issues:** E.g., `5 issues` (if issue tracking is enabled).
    * **Alerts:** E.g., `2 alerts` (if background validation is enabled).
    * **License:** Your current license plan (e.g., `pro`, `community`).
    * **Tombstone:** Shows pending undo actions (e.g., `u: deleted file 5s`).
    * **Running / Review:** E.g., `2 running · 1 review`. Shows active agents and pending approvals.
    * **Cost:** E.g., `$0.15`. The estimated API cost of the current session or total run.
    * **Time:** Elapsed time since the application started.
    * **Mode:** The current edit mode (e.g., `[INSERT]`).
    * **Model:** The active LLM model (e.g., `claude-3-5-sonnet`).
    * **Context:** The token usage percentage (e.g., `ctx 45%`).

## Help Overlay

> 🎥 **Video Placeholder:** [Demonstrate pressing `?` to open the Help Overlay, scrolling through the shortcuts, and pressing `?` again to close it.]

If you ever forget a keybinding, press **`?`** to toggle the **Help Overlay**. It provides a comprehensive, scrollable list of all available shortcuts for the current view and mode. Press `?` or `Esc` to close it.

## Text Selection (Copy/Paste)

Because Spur uses mouse capture to enable scrolling with the mouse wheel, you cannot select text normally. However, you can bypass this by holding a modifier key while dragging:

* **macOS (iTerm2 / WezTerm / Ghostty):** `Option+drag`
* **macOS (Terminal.app):** `Fn+drag`
* **Linux (Kitty / Alacritty / GNOME / Konsole):** `Shift+drag`
* **Windows Terminal:** `Alt+drag`dows Terminal:** `Alt+drag`
