# Product demos

This directory contains small, web-optimized product demonstrations referenced
by SPUR's public documentation.

| Demo | Video | Poster | Capability |
|---|---|---|---|
| Install and initialize | `spur-install-and-init.webm` | `spur-install-and-init-poster.jpg` | Package install, agent discovery, brain selection, and first launch |
| Help and shortcuts | `spur-help-and-shortcuts.webm` | `spur-help-and-shortcuts-poster.jpg` | Navigation modes and keyboard reference |
| Session navigation | `spur-session-navigation.webm` | `spur-session-navigation-poster.jpg` | Session picker, lineage, and command palette |
| TUI tour | `spur-tui-tour.webm` | `spur-tui-tour-poster.jpg` | Plans, sprints, workers, and task detail surfaces |
| Live delegation | `spur-live-delegation.webm` | `spur-live-delegation-poster.jpg` | Parallel worker dispatch and live monitoring |
| Kiro brain | `spur-kiro-brain-multi-agent.webm` | `spur-kiro-brain-multi-agent-poster.jpg` | Cross-vendor orchestration and outcome consolidation |
| DAG-aware multi-agent | `spur-dag-aware-multi-agent.webm` | `spur-dag-aware-multi-agent-poster.jpg` | Staged dependencies, parallel branches, and review convergence |

Keep this directory curated:

- Prefer WebM for video and a compressed JPEG or WebP poster.
- Keep each public asset under 10 MB.
- Add only finished demos that explain a current product workflow.
- Keep raw recordings, editing projects, and launch-production media outside the
  OSS repository.
