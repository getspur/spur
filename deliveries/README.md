# deliveries/ (not part of the OSS product tree)

Finished explainer deliveries (masters, plate reels, voice takes, manifests)
are **gitignored** here. They are production outputs, not product source.

## Where this content should live

- `getspur/spur-media` (or internal asset store)
- Or alongside the HyperFrames / explainer project that produced them

Do not commit `.mp4` / `.mp3` / voice auditions into `getspur/spur`.
