# Frame: Liquid Hero

Use this template when a video needs a refined hero or opener with a centered
headline over a moving liquid-gradient field.

## Inputs

- `headline`: replace the `Fluid Strategy` text in the `h1`.
- `subtext`: replace the supporting sentence in `.subtext`.
- Optional eyebrow text can be edited in `.eyebrow`.

## Usage

Keep the HTML self-contained and inline. The gradient field and soft highlight
layers animate on page load with CSS keyframes, so no JavaScript or external
assets are required for capture.
