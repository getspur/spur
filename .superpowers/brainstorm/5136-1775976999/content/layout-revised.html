SPUR TUI — Revised Design

After MCTS evaluation: vertical split is the clear winner. Here's why, plus the refined design.

Why Option A (horizontal sidebar) was eliminated

At 80 columns, a 30% sidebar = 24 chars. A full agent line needs ~50 chars (⠋ kiro BRAIN working 3m42s $0.82). The sidebar physically can't fit the information we need to show. You'd have to split it across two panels (agents + cost separately) or truncate fields, both of which defeat the redesign's goals.

Refined Design: Vertical Split with Smart Log

┌─ Agents ────────────────────────────────────────────────────────────┐ ⠋ kiro BRAIN working 3m 42s $0.82 ├─ ⠋ claude WORKER working 2m 15s $0.42 └─ ○ codex WORKER idle ├─ Activity ──────────────────────────────────────────────────────────┤ 10:32:01 [brain:kiro] Tool: bash — git status 10:32:03 [brain:kiro] → Delegating to claude: fix auth module 10:32:05 [worker:claude] Tool: write — src/auth.rs 10:32:08 [worker:claude] Tool: bash — cargo test 10:32:10 [worker:claude] ▸ ...verifying the token validation logic passes all 10:32:12 [worker:claude] ✓ Delegation complete ($0.42, 2m 15s) 10:32:14 [brain:kiro] Tool: bash — git diff 10:32:16 [brain:kiro] ▸ ...reviewing the changes to ensure correctness be 10:32:18 [brain:kiro] Tool: bash — git add -A && git commit ▼ following └─────────────────────────────────────────────────────────────────────┘ [q] [Tab] [j/k] [/]filter [v]verbose [?]help $1.24 │ 3m 42s │ SPUR

Key Design Decisions

Log Content

Actions shown immediately (tool calls, delegations, errors). Text deltas batched at 500ms into condensed previews: ▸ ...last 50 chars of agent output. Press v for full verbose text.

Agents Panel

Capped at max 40% of screen height. Scrollable if more agents. Brain→worker tree with inline status, elapsed, cost. Spinner animation for working agents.

Scroll Behavior

"Sticky bottom" — auto-follows new entries. Scrolling up pauses auto-follow. Shows ▼ following indicator when active. Scrolling back to bottom re-enables.

Empty State

When no sessions active: centered message "No active sessions. Start: spur run 'task'". When complete: summary replaces agents panel.

At narrow widths: role abbreviates (B/W), status truncates, timestamps shorten, prefixes drop role. All info still accessible — just compressed.
