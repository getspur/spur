SPUR TUI Layout

Which layout works better for monitoring a multi-agent orchestrator?

A

Horizontal Split (current)

Left sidebar for agents + cost, right panel for logs. Like gitui/lazygit.

spur watch — 80x24
┌─ Agents ────────┬── Activity Log ──────────────┐ ⠋ kiro BRAIN │ 10:32:01 [brain:kiro] ● claude WRKR │ Tool: bash — git status ○ codex WRKR │ 10:32:03 [brain:kiro] │ Delegating to claude... ├─ Cost ──────────┤ 10:32:05 [worker:claude] kiro $0.82 │ Tool: write auth.rs claude $0.42 │ 10:32:08 [worker:claude] total $1.24 │ Tool: bash — cargo test │ 10:32:12 ✓ Delegation complete └─────────────────┴──────────────────────────────┘ [q]uit [Tab] [↑↓]scroll SPUR v0.1

Pros

  • Familiar gitui/lazygit pattern
  • Agents always visible while reading logs

Cons

  • Cramped on narrow terminals (<80 cols)
  • Cost panel squeezed below agents
  • Agent info split across two panels
B

Vertical Split (proposed)

Agents tree on top (auto-sized), activity log fills below. Like k9s/bottom.

spur watch — 80x24
┌─ Agents ────────────────────────────────────────┐ ⠋ kiro BRAIN working 3m 42s $0.82 ├─ ⠋ claude WORKER working 2m 15s $0.42 └─ ○ codex WORKER idle ├─ Activity Log ──────────────────────────────────┤ 10:32:01 [brain:kiro] Tool: bash — git status 10:32:03 [brain:kiro] → Delegating to claude: fix auth 10:32:05 [worker:claude] Tool: write — src/auth.rs 10:32:08 [worker:claude] Tool: bash — cargo test 10:32:12 [worker:claude] ✓ Delegation complete ($0.42) 10:32:14 [brain:kiro] Tool: bash — git diff 10:32:18 [brain:kiro] ✓ Session complete ▼ following └─────────────────────────────────────────────────┘ [q] [Tab] [j/k] [/]filter [?]help $1.24 3m 42s SPUR

Pros

  • Works at any terminal width (even 40 cols)
  • All agent info on one line (name, status, time, cost)
  • Tree shows brain→worker hierarchy
  • Log gets maximum vertical space

Cons

  • Agents panel shrinks when many agents
  • Less familiar than sidebar layouts
