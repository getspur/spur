# Growth-loop daily artifact schema

Each `resource/growth-loop/YYYY-MM-DD.md` MUST match this structure. Sections in this exact order.

```markdown
# Growth loop — YYYY-MM-DD

**Theme of the day:** <one sentence, must differ from last 3 days>
**Generated:** <ISO timestamp> by growth-loop skill

## Yesterday's results
*Filled in by hand the next morning before today's run, or left as `pending`.*
- X posts shipped: <list URLs + impressions/likes if known>
- Reddit posts/replies shipped: <list URLs + upvotes/replies if known>
- Notes: <one line on what worked / didn't>

## Research — X (last 24h)
- **Trend:** <claim> — <URL> — "<excerpt>"
- **Mention of SPUR or peers:** <claim> — <URL> — "<excerpt>"
- **Underserved question:** <claim> — <URL> — "<excerpt>"

## Research — Reddit (last 24h)
For each subreddit scanned:
- **r/<name>:** top relevant post — <URL> — "<title>" — <reply count>
- **Under-replied questions** (<5 replies, on-topic for SPUR):
  - <URL> — "<title>" — <subreddit> — <reply count>

## Research — Competitors / peers (last 24h)
- **<peer name>:** shipped/posted <one line> — <URL>

## Synthesis
- Why this theme today, in 2 sentences.
- What angle differentiates from the last 3 days.

## Drafts — X
### Single post
> <≤270 chars, SPUR voice>

### Thread outline (3–7 tweets)
1. <hook>
2. ...
N. <CTA — soft, not salesy>

### Images (optional, generated by growth-loop-media → codex worker)
- `resource/growth-loop/YYYY-MM-DD/images/<slug>-1.png` — model: gpt-image-1 — prompt: "<exact prompt sent>"
- Or: `## Images — codex-unavailable` / `## Images — api-error: <message>` / `## Images — skipped (filler)`

## Drafts — Reddit
### Text post — r/<subreddit>
**Title:** <title>
**Body:**
> <body, peers-not-competitors framing>

## Drafts — Reddit replies
For each target question:
### Reply to <URL>
**Subreddit:** r/<name>
**Original question (excerpt):** "<one line>"
**Reply:**
> <answer the question first; SPUR mention only if naturally relevant>

## Summary (for terminal)
- Theme: <…>
- Posts drafted: X=<n> Reddit=<n>
- Replies drafted: <n>
- Top opportunity: <one line — which draft to ship first and why>
- Artifact: resource/growth-loop/YYYY-MM-DD.md
```
