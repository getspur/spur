# SPUR Launch Package

Release-ready assets for the 60-second SPUR brain-control-tower launch film.

## Deliverables

- `SPUR-Launch-Master-1080p.mp4` — publishing master
- `SPUR-Launch-Poster.jpg` — 16:9 end-card poster or video thumbnail
- `SPUR-Launch-Editable.palmier/` — self-contained editable Palmier project
- `SPUR-Launch-QA-Contact-Sheet.jpg` — visual QA reference across the full cut
- `SHA256SUMS.txt` — integrity hashes

## Master specification

- Duration: 60 seconds
- Video: H.264, 1920x1080, 30 fps
- Audio: AAC, 48 kHz, stereo
- Narrative: user works with the brain; the brain delegates through Plan,
  Loop, and Ad hoc execution; worker evidence returns to the control tower;
  the brain reviews first and escalates only critical decisions to the human
- Audio treatment: music bed only; narration intentionally omitted

## Launch copy

**Title:** SPUR — Talk to the brain. Watch the work.

**One-liner:** A terminal control tower for coding agents.

**Short description:** Work directly with one brain agent while SPUR plans,
delegates, observes, and reviews the workers underneath. Routine work moves
forward through brain review; critical decisions return to the human with
evidence and explicit choices.

## Publishing

Use the MP4 as the launch-video upload and the poster as its thumbnail. Keep
the Palmier package with the release archive for future recuts. The QA contact
sheet is a review aid and does not need to be published.
