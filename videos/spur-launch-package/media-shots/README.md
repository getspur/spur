# SPUR Media Shots

Publishing stills and press-ready product images derived from the approved
launch film and its HyperFrames control-flow insert.

## Folders

- `product/` — full-resolution 1920x1080 stills from the 60-second launch master
- `hyperframes/` — full-resolution 1920x1080 explanatory visualization stills
- `web/` — 1280x720 JPEG derivatives for lightweight web publishing
